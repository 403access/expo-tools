Three toolchains, one panel

Everything that's building, right now

No terminals to hunt down, no guessing whether Metro survived the last save.

Metro

Expo

Detects the running dev server, its project, port and uptime — then probes /status to prove it is actually alive.

  • Scannable Expo Go QR from your LAN URL
  • Copy the dev URL or open it in the browser
  • Reveal the project folder, stop Metro cleanly
Xcode

Xcode

Spots command-line xcodebuild runs and builds started from the Xcode UI, with scheme and destination.

  • Booted simulators with their runtime
  • Most recent .app product and build age
  • Open Xcode, open Simulator, reveal the build
Gradle

Android

Tracks Gradle builds through daemon logs and wrapper processes, showing the exact task being executed.

  • Live task name and CPU usage
  • Emulators and physical devices via adb
  • Launch Android Studio in a click

Detail

Dense where it matters, calm when it's quiet

Each platform gets a card with a status pill, live activity rows and its own action bar. When nothing is running, the panel simply says so — no fake progress bars, no noise.

  • Platform-tinted cards: Expo, Xcode, Android
  • Monospaced metrics for ports, PIDs, runtimes and Gradle tasks
  • Simulators and devices listed with their online state

Install

Running in about a minute

Requires macOS 14+, Xcode command line tools, and XcodeGen.

  1. 1

    Install XcodeGen

    $ brew install xcodegen
  2. 2

    Clone the repo

    $ git clone https://github.com/403access/expo-tools.git
  3. 3

    Build & launch

    $ ./scripts/run.sh

Look for the hammer

Expo Tools has no Dock icon — it lives in the menu bar. Drag the built app into /Applications and add it to your login items to keep it around.
